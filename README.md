# Leksmedia — The YouTube Personal Brand Operating System

> The complete YouTube personal brand platform for creators and founders. Define your category of one with the Ikigai blueprint, discover breakout 48-hour outlier opportunities, and generate production-ready 8–12 minute video scripts.

---

## ⚡ Core Features

- **Ikigai Category Blueprint:** Guided 4-pillar strategic positioning engine (Passion, Skills, Market Problem, Monetization) that defines your unique creator avatar and differentiation angle.
- **YouTube 48-Hour Outlier Velocity Scanner:** Algorithmic intelligence system tracking rapid-growth videos, view velocities, and retention anomalies across target niches.
- **Long-Form Script Studio:** Full 8–12 minute structured YouTube video scripts complete with 7-step retention hooks, content pacing, and visual B-roll cues.
- **Channel Content Diagnostics:** 3-tier channel diagnostics auditing abnormal catalog winners, break-even videos, and retention drop-offs.
- **Enterprise-Grade Legal Architecture:** Comprehensive Terms of Service, Privacy Policy (YouTube API Services compliant, zero public model training guarantee), and 14-Day Satisfaction Guarantee Refund Policy.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/leksautomate/Leksmedia.git
   cd Leksmedia
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
